04 / About

Hi, I'm Sanskar

I'm a third-year Electronics and Telecommunication Engineering student at PICT (Pune Institute of Computer Technology) and a Software Engineer Intern at MindstriX Technologies LLP, where I work on LLM integration, API development and AI R&D.

I like projects where code meets the physical world: computer vision on embedded hardware, sensor fusion, and AI that stays inside deterministic rules so it can be trusted with money, crops or security decisions.

Right now I'm building AI-native Android apps that combine the Gemini API with real-world sensor data. I'm open to internships and collaborations, and the fastest way to reach me is LinkedIn.
