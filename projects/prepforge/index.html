PrepForge

Adaptive placement preparation for SDE-1 and new-grad roles

Built by Sanskar Tiwari (santiwari07)

Live demo ↗ Source on GitHub ↗

PrepForge is an adaptive, evidence-based preparation platform for fresher (SDE-1 and new-grad) roles at big product companies.

It covers DSA, SQL and DBMS, OOP in C++ and Java, operating systems, networks, system design and DevOps, and adapts to what you already know.

What it does

  • Covers DSA, SQL, DBMS, OOP, OS, networks, system design and DevOps
  • Adaptive, evidence-based practice
  • Aimed at SDE-1 and new-grad interviews at product companies

Built with

  • TypeScript
  • Vercel
