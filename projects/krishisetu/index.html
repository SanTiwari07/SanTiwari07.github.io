KrishiSetu

Blockchain-based agricultural supply chain with farm-to-table traceability

Built by Sanskar Tiwari (santiwari07)

Live demo ↗ Source on GitHub ↗

KrishiSetu is an agricultural supply chain management system that uses blockchain to bring transparency, traceability and trust from farm to table.

Built by the KrishiSahAI team, KrishiSetu tracks agricultural produce through the supply chain so every step can be traced and trusted.

What it does

  • Farm-to-table traceability on a blockchain ledger
  • Transparent records for farmers, traders and buyers
  • Web app built with TypeScript

Built with

  • TypeScript
  • Blockchain
  • Firebase
