Plant Disease Detector

Leaf-image plant disease detection with EfficientNetB3 and Streamlit

Built by Sanskar Tiwari (santiwari07)

Source on GitHub ↗

A deep learning system that detects plant diseases from leaf images using EfficientNetB3 and transfer learning, with an interactive Streamlit web interface.

Upload a photo of a leaf and the model classifies the disease, so farmers and students can get a fast first diagnosis.

What it does

  • EfficientNetB3 with transfer learning
  • Image classification across multiple plant diseases
  • Interactive Streamlit web app

Built with

  • Python
  • Deep learning
  • EfficientNetB3
  • Transfer learning
  • Streamlit
