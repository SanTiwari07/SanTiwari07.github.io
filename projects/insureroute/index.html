InsureRoute

Supply-chain intelligence with weather-aware rerouting and dynamic insurance pricing

Built by Sanskar Tiwari (santiwari07)

Source on GitHub ↗

InsureRoute connects predictive routing with financial hedging: it watches real-time weather, predicts transit disruptions, reroutes shipments and prices cargo insurance by actual route risk.

Global logistics is fragile and cargo insurance is rigid. Alternate routes are found only after a delay happens, and shippers pay the same premium whether the truck crosses a clear highway or a flooded monsoon zone.

InsureRoute brings the scattered data together into one view for risk managers.

What it does

  • Isolation Forest anomaly detection over weather severity, historical delays and vehicle telemetry
  • Algorithmic rerouting before disruptions hit
  • Dynamic, actuarial pricing of cargo risk

Built with

  • Python
  • Machine learning
  • Isolation Forest
