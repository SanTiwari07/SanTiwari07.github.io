Smart Solar Panel

Sun-tracking solar panel with Arduino, LDR sensors and a servo

Built by Sanskar Tiwari (santiwari07)

Source on GitHub ↗

A smart solar panel that uses an Arduino UNO, LDR sensors and a servo motor to follow the direction of sunlight and adjust the panel's angle.

Two light sensors compare brightness on each side, and the servo turns the panel toward the brighter side to collect more energy.

What it does

  • Single-axis sun tracking
  • LDR light comparison with servo control
  • Arduino UNO build

Built with

  • C++
  • Arduino UNO
  • LDR
  • Servo
