LeetCode Tracker

Chrome extension that saves your LeetCode submissions to GitHub automatically

Built by Sanskar Tiwari (santiwari07)

Source on GitHub ↗

LeetCode Tracker is a Chrome extension that automatically saves your LeetCode submissions to GitHub, organises problems by topic, and gives you a dashboard of solved problems, recent activity and monthly progress.

It powers the LeetCodeSolved repository, where solutions are synced and organised by topic: arrays, dynamic programming, trees, graphs, SQL and more.

What it does

  • Automatic commit of every accepted submission
  • Problems organised into folders by topic
  • Progress dashboard with monthly activity

Built with

  • JavaScript
  • Chrome Extension
  • GitHub API
