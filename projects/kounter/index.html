Kounter

Offline-first shop-audit concept for India's small shops, built for the iQOO 15

Built by Sanskar Tiwari (santiwari07)

Live demo ↗ Source on GitHub ↗

Kounter (हर माल गिना हुआ, every item counted) is an offline-first shop-audit concept that turns the iQOO 15's sensors into a delivery counter, expiry gate, freezer remote and Hindi voice assistant for small shops.

Designed with my team HoloTrio for the iQOO 15, focused on productivity for small shopkeepers.

The repository is a design and interactive prototype: a scroll-driven 3D showcase website plus the engineering specification for the Android app.

What it does

  • Delivery counting, expiry checks and freezer control from one phone
  • Hindi voice assistant for shopkeepers
  • Works offline-first
  • Showcase site with a scroll-driven 3D phone, GSAP, Lenis and a Three.js background

Built with

  • Three.js
  • GSAP
  • JavaScript
  • Android (spec)
