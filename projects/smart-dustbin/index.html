Smart Dustbin

Dustbin that sorts wet and dry waste automatically

Built by Sanskar Tiwari (santiwari07)

Source on GitHub ↗

A smart garbage dustbin that automatically detects and classifies waste as wet or dry using a soil moisture sensor and an ultrasonic sensor.

The ultrasonic sensor detects when waste arrives, and the moisture sensor decides which side it belongs to.

What it does

  • Automatic wet and dry waste classification
  • Ultrasonic presence detection
  • Low-cost sensor-based build

Built with

  • C++
  • Microcontroller
  • Ultrasonic sensor
  • Soil moisture sensor
