AgriAdvisor

Reinforcement learning environment for safe crop pest and disease advice

Built by Sanskar Tiwari (santiwari07)

Source on GitHub ↗

AgriAdvisor is an OpenEnv-compatible reinforcement learning environment where AI agents learn to give safe, practical pest and disease advisories grounded in the realities of Indian smallholder farming.

Generic AI advice can recommend treatments a smallholder cannot afford or apply safely. AgriAdvisor rewards agents for advice that is safe and practical in real Indian farm conditions.

What it does

  • OpenEnv-compatible environment for training and evaluating agents
  • Rewards safe, practical advisories
  • Focused on Indian smallholder agriculture

Built with

  • Python
  • Reinforcement learning
  • OpenEnv
