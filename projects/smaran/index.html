Smaran

Offline-first memory and intelligence for edge fleets, built on Qdrant Edge

Built by Sanskar Tiwari (santiwari07)

Live demo ↗ Source on GitHub ↗

Smaran is offline-first memory and intelligence for edge fleets. It keeps working when the network vanishes, seals private notes on-device, and uses version vectors to flag clashing field reports instead of silently dropping one.

Picture two maintenance technicians, or two rovers, sent into a network dead zone: a steel-reinforced basement, a remote mine, another planet. Each keeps working and writing reports. When they reconnect, most systems keep the last write and lose the other. Smaran flags the conflict instead.

Built on Qdrant Edge on every device and Qdrant Server as the fleet hub.

What it does

  • Local vector search keeps working with no network
  • Private notes are sealed on-device by construction
  • Mathematical version vectors detect and surface conflicting reports
  • Mission-control dashboard, measured benchmarks and CI

Built with

  • Python
  • Qdrant Edge
  • Qdrant
  • Vector search
