Nova

Autonomous household commerce agent with a deterministic safety gate

Built by Sanskar Tiwari (santiwari07)

Live demo ↗ Watch video ↗ Source on GitHub ↗

Nova is an autonomous household commerce agent: it tracks household consumption, reorders essentials before they run out, and deliberately refuses to spend when stock is healthy.

Keeping track of household inventory and small daily purchases is an invisible, constant burden. Nova takes it over while keeping spending safe.

The agent runtime is separated from a pre-commit safety gate, so probabilistic reasoning never moves money on its own.

What it does

  • Predictive restock, for example reordering milk based on live consumption rate
  • Intelligent restraint: chooses to do nothing when pantry stock is healthy
  • Deterministic safety gate checks every order before it is placed

Built with

  • Python
  • AWS Strands Agents
