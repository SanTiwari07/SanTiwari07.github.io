Push-Up Counter

Webcam push-up counter using pose detection in the browser

Built by Sanskar Tiwari (santiwari07)

Live demo ↗ Source on GitHub ↗

Push-Up Detection uses a webcam feed to detect human body keypoints and counts push-ups from body movement, entirely in the browser.

Pose keypoints are tracked frame by frame, and a simple movement rule counts each full push-up. A companion project, Skeleton Detection, shows the raw PoseNet skeleton.

What it does

  • Runs in the browser with just a webcam
  • Counts repetitions from body keypoint movement
  • Live demo on GitHub Pages

Built with

  • JavaScript
  • Pose detection
  • Webcam
